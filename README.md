A small fan-made C++ game inspired by *JoJo’s Bizarre Adventure*, recreating DIO’s iconic time-stop effect.

The game is made **directly with the Windows API (WinAPI) and GDI** — no Unity, no Unreal Engine, and no big game engines. Just C++ and native Windows technologies.

The idea is simple: stop time, face your enemies, and try to defeat them before time starts moving again. The project focuses on recreating the atmosphere and visual style of DIO's iconic ability.

## ✨ Features
⏸️ Time-stop effect inspired by *JoJo’s Bizarre Adventure*
👾 Enemies and simple arcade-style gameplay
🎨 Custom visuals rendered using WinAPI and GDI
🔊 Sound effects
🎬 GIF comparisons between the original anime and the in-game recreation

## 🛠️ Tech Stack

**Language:** C++
**Windowing:** Windows API (WinAPI)
**Graphics:** GDI
**IDE:** Visual Studio
